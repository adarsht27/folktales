# folktales
NLP project to analyse folktales from Germany and India and see how they were similar or different in depiction, cultural values and possibly much more to be explored.

## Project structure

```text
folktales/
  README.md
  requirements.txt
  data/raw/        <- downloaded files, never edited
  data/interim/    <- one file per tale, after splitting
  data/processed/  <- cleaned passages
  data/manifest.csv
  notebooks/
  scripts/download_gutenberg.py
```
